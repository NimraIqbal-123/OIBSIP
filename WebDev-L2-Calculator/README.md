# JavaScript Calculator

## Project Overview

This project is a fully functional browser-based calculator developed as part of the **Oasis Infobyte Web Development & Design Internship**.

The calculator performs basic arithmetic operations through a user-friendly button interface and also supports keyboard input.

## Features

* Addition (`+`)
* Subtraction (`−`)
* Multiplication (`×`)
* Division (`÷`)
* Decimal number input
* Equals (`=`) button
* Clear (`C`) button
* Backspace (`⌫`) button
* Operator chaining
* Standard operator precedence
* Division-by-zero protection
* Keyboard support
* Responsive button layout using CSS Grid
* Event listeners using Vanilla JavaScript
* No inline `onclick` attributes
* No `eval()` function

## Technologies Used

* HTML5
* CSS3
* JavaScript (Vanilla)

## Operator Precedence

The calculator follows normal arithmetic precedence.

For example:

```text
5 + 3 × 2 = 11
```

Multiplication is performed before addition.

## Division by Zero

The calculator prevents division by zero and displays an error message instead of crashing.

Example:

```text
10 ÷ 0
```

Output:

```text
Cannot divide by 0
```

1. Download or clone the project.

4. Use the calculator buttons or your keyboard to perform calculations.
