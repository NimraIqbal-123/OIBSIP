# Marie Curie Tribute Page

A responsive tribute page dedicated to **Marie Curie**, created as part of the **OIBSIP Web Development & Design — Level 2, Task 2**.

## 📌 Project Overview

This project presents a tribute to Marie Curie, a pioneering scientist known for her groundbreaking research on radioactivity.

The page includes her biography, important achievements, a timeline of key moments, and a notable quote.

## ✨ Features

* Marie Curie's introduction and tagline
* Historical portrait
* Four-paragraph biography
* Key achievements timeline
* Styled quote section
* Multiple background colors
* Serif and sans-serif typography
* Responsive design for mobile, tablet, and desktop
* Source links for research and image attribution

## 🛠️ Technologies Used

* HTML5
* CSS3
