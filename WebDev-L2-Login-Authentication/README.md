# 🔐 Login Authentication System

A responsive, client-side Login Authentication System developed using HTML, CSS, and JavaScript as part of my Oasis Infobyte (OIBSIP) Web Development and Design Internship.

## ✨ Features

- User registration with username and email
- Password validation (minimum 8 characters and at least one number)
- Duplicate username and email detection
- Login with username or email
- Generic error message for invalid credentials
- Protected dashboard view after successful login
- Logout functionality
- Session restoration after page refresh
- LocalStorage for demo account storage
- Responsive and compact user interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage
- SessionStorage

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using Live Server, or open it directly in a browser.
4. Register a test account.
5. Log in using your registered username or email and password.

## 🔒 Security Note

This project is intended for learning and demonstration purposes. It stores demo passwords in browser LocalStorage and does not provide production-grade authentication. A real authentication system should use a secure backend, password hashing, and server-side session validation.
