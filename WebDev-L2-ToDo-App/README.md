# To-Do Web App — OIBSIP Task 3

A responsive and interactive To-Do List web application developed as part of the **Oasis Infobyte Web Development & Design Internship — Task 3**.

The application allows users to add, manage, edit, complete, and delete daily tasks through a simple and user-friendly interface.

## 🚀 Features

* Add new tasks
* Display newly added tasks in the Pending Tasks section
* Mark tasks as completed
* Automatically move completed tasks to the Completed Tasks section
* Edit task text inline
* Delete tasks permanently
* Display pending and completed task counters
* Show empty-state messages when lists are empty
* Display task timestamps
* Save tasks using browser `localStorage`
* Tasks remain available after refreshing the page
* Press **Enter** to quickly add a task
* Press **Enter** while editing to save changes
* Press **Escape** while editing to cancel changes
* Responsive design for desktop and mobile devices

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* DOM Manipulation
* Browser Local Storage

## ⚙️ How It Works

### Add Task

Enter a task in the input field and click **Add Task**. The new task immediately appears in the Pending Tasks section.

### Complete Task

Click **Mark Complete** to move a task from Pending Tasks to Completed Tasks.

### Edit Task

Click **Edit** to modify the task text directly within the task card. Click **Save** to save the changes or **Cancel** to discard them.

### Delete Task

Click **Delete** to permanently remove a task.

### Local Storage

Tasks are stored in the browser using JavaScript `localStorage`, allowing them to remain available even after the page is refreshed.
